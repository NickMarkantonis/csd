## 1. Τελεστές
- Τύποι Τελεστών
    - Προθεματικός (prefix): `fx` (π.χ `-5`)
    - Ενθεματικός (infix): `yfx` (π.χ `2 + 3`)
    - Επιθεματικός (postfix): `xf` (π.χ `5!`)
- Προτεραιότητα:
    - `*` έχει υψηλότερη προτεραιότητα από `+`
    - Παράδειγμα `2 + 3 * 5` <-> `+(2,*(3,5))`
- Ορισμός νέων τελεστών:
    ```prolog
    :- op(500,xfx,!).           % ορίζει τελεστή παραγοντικού
    N ! F :- factorial(N,F).    % Χρήση 4 ! result -> result = 24
    ```

## 2. Υπολογισμός Αριθμιτικών Εκφράσεων
- `is/2` Υπολογίζει αριθμητικές εκφράσεις
    - Παράδειγμα
        ```prolog
        ?- X is 5 + 2.  % X = 7
        ?- 10 is 5 +5.  % true
        ```
    - Προσοχή
        - Το δεξί όρισμα πρέπει να είναι πλήρως ορισμένο (χωρίς ελέυθερες μεταβλητές)
        - `X is X + 1` είναι λάθος (αδύνατη λογική σχέση)
- Τελεστές Σύγκρισης:
    - `=`, `\=`, `==`, `=\=`, `>`, `<`, `>=`, `=<`
    - Παράδειγμα
        ```prolog
        ?- 5 \= 6.          % true
        ?- 5 + 2 =:= 3 + 4. % true
        ```

## 3. Άρνηση (Negation)
- `\+` ή `not.1`: Βασίζεται στην "υπόθεση του κλειστού κόσμου"
    - Παράδειγμα
        ```prolog
        man(peter). woman(helen).
        ?- \+ man(helen)    % true (δεν μπορεί να αποδειχθεί)
        ?- \+ man(X)        % false (υπάρχει τουλάχιστον ένας άνδρας)
        ```
    - Προσοχή: Η σειρά των κανόνων επηρεάζει τα αποτελέσματα
        ```prolog
        ?- man(X), \+ woman(X).     % X = peter ; X = jimmy
        ?- \+ woman(X), man(X).     % false (λόγω σειράς εκτέλεσης)
        ```


## 4. Ενοποίηση (Unification)
- Ορισμός: Διαδικασία ταιριάσματος δύο όρων με αντικαταστάσεις
- Κανόνες:
    1. Δύο σταθερές ενοποιούνται αν είναι ίδιες
    2. Μεταβλητή ενοποιείται με οποιονδήποτε όρο
    3. Σύνθετοι όροι ενοποιούνται αν έχουν ίδιο function και ενοποιήσιμα ορίσματα
- Παραδείγματα:
    ```prolog
    ?- foo(a,b) = foo(X,Y). % X = a, Y = b
    ?- [a,b,c] = [X|Y].     % X = a, Y = [b,c]
    ?- X = father(X)        % Ατέρμονη ενοποίηση (λάθος)
    ```

## 5. Είδη Ισότητας
- `=`: Ενοποίηση όρων (χωρίς υπολογισμούς)
    ```prolog
    ?- 2 + 3 = +(2,3)   % true
    ```
- `==`: Αριθμητική ισότητα (με υπολογισμούς)
    ```prolog
    ?- 5 + 2 =:= 3 + 4  %true
    ```
- `is`: Υπολογίζει το δεξί όρισμα και το αντιστοιχεί στο αριστερό
    ```prolog
    ?- X is 5 + 2       % X = 7
    ```

## 6. Σημαντικές Παρατηρήσεις
- Ατέρμονοι βρόχοι: Προκύπτουν από λανθασμένους αναδρομικούς ορισμούς (π.χ `X = father(X)`)
- Σειρά κανόνων: Η Prolog εκτελεί κανόνες από πάνω προς τα κάτω και subgoald από αριστερά προς τα δεξιά
- Μεταβλητές: Μία μεταβλητή μπορεί να πάρει μόνο μία τιμή (single assignment)
