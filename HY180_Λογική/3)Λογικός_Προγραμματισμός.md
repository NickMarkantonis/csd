## Εισαγωγή στον Λογικό Προγραμματισμό
- Ο λογικός προγραμματισμός (LP) ανήκει στον **Δηλωτικό Προγραμματισμό**, όπου ο προγραμματιστής περιγράφει τί θέλει να επιλυθεί, όχι **πώς**
- Βασίζεται σην **μαθηματική λογική** και χρησιμοποιείται σε εφαρμογές Τεχνητής Νοημοσύνης όπως επεξεργασία φυσικής γλώσσας, έμπειρα συστήματα, και βάσεις δεδομένων

## Η γλώσσα Prolog
- **Prolog (Programming in Logic)**: Αντιπροσωπευτική γλώσσα λογικού προγραμματισμού
- Χαρακτηριστικά:
    - Βασίζεται σε **κατηγορηματική λογική** και **όρους Horn**
    - Διαθέτει μηχανισμούς ενσποίησης (unification) και οπισθοδρόμησης (backtracking)

## Προστακτικός vs Δηλωτικός Προγαμματισμός
- **Προστακτικός Προγραμματισμός** (C, Java, etc)
    - Περιγράφει βήματα και έλεγχο ροής
    - Ο προγραμματιστής ορίζει τον αλγόριθμο.
- **Δηλωτικός Προγραμματισμός** (Prolog)
    - Περιγράφει λογικές σχέσεις και γεγονόντα
    - Το σύστημα αναλαμβάνει την επίλυση

## Βασικές έννοιες της Prolog
- **Γεγονόντα (Facts)**: Δηλώσεις που είναι πάντα αληθείς
    Παράδειγμα: `mother(helen,maria)`
- **Κανόνες (Rules)**: Σχέσεις που ισχύουν υπό συνθήκες
    Παράδειγμα `grandparent(X,Z) :- parent(X,Y), parent(Y,Z)`
- **Ερωτήσεις (Queries)**: Επιλύονται από το σύστημα για να εξαχθούν συμπεράσματα
    Παράδειγμα `?- grandparent(X,george)`

## Σύνταξη Prolog
- **Σταθερές**: Άτομα (ξεκινούν με πεζό γράμμα) ή αριθμοί
- **Μεταβλητές**: Ξεκινούν με κεφαλαίο γράμμα (π.χ `X`, `Y`)
- **Ανώνυμη Μεταβλητή**: `_` (δεν ενδιαφέρει η τιμή της)
- **Τελεστές**:
    - `:-` (συνεπαγωγή), `,` (ΚΑΙ), `;` (Ή), `=` (ενσποίηση)

## Μηχανισμοί Εκτέλεσης
- **Ενσποίηση (Unification)**: Ταίριασμα όρων με ανάθεση τιμών σε μεταβλητές
- **Οπισθοδρόμηση (Backtracking)**: Αναζήτηση όλων των πιθανών λύσεων

## Παραδείγματα
- Υπολογισμός Παραγοντικού
    ```prolog
    factorial(0,1)
    factorial(N,F) :- N > 0, N1 is N - 1, factorial (N1,F1), F is N * F1
    ```
- Οικογενειακές Σχέσεις
    ```prolog
        parent(X,Y) :- father(X,Y)
        parent(X,Y) :- mother(X,Y)
        grantparent(X,Z) :- parent(X,Y), parent(Y,Z)
    ```

## Πλεονεκτήματα Prolog
- **Δηλωτικότητα** Εστίαση στη λογική περιγραφή
- **Απλότητα**: Έυκολη αναπαράσταση γνώσης
- **Αυτόματη Αναζήτηση**: Εύρεση λύσεων χωρίς ρητό αλγόριθμο

## Κατηγοριματική Λογική
- Επέκταση της προτασιακής λογικής με όρους, κατηγορήματα και ποσοδείκτες
- Παράδειγμα: `F(a)` (ιδιότητα), `R(a,b)` (σχέση)

## Όροι Horn
- Χρησιμοποιούνται για την αναπαράσταση γεγονόντων και κανόνων
- Μορφή: `A :- B1,B2,...,Bn` (όπου `Α` είναι η κεφαλή και `Β1,...,Βn` το σώμα)

## Σύνθετοι Όροι (Compound Terms)
- **Ορισμός**: Ένας σύνθετος όρος έχει τη μορφή `f(t1,t2,...,tn)` όπου
    - `f` είναι το συναρτησιακό σύμβολο
    - `t1,t2,...,tn` είναι τα ορίσματα
- **Χρήση**: Αναπαριστά σύνθετες δομές δεδομένων, όπως π.χ `info(greek,birthday(30,6,1975), job(teacher))`
- **Build-in κατηγόρημα**: `compound/1` ελέγχει αν ένας όρος είναι σύνθετος

## Σημαντικότητα Σωστής Αναπαράστασης
- Παράδειγμα: Αναπαράσταση ομάδων χρήστων
    - Λάθος τρόπος: `admin(george)` (δεν επιτρέπει ερωτήσεις όπως "Σε ποιές ομάδες ανήκει ο george;")
    - Σωστός τρόπος: `belongs_to(admin,george)` (επιτρέπει ερωτήσεις με μεταβλητές)
- Κίνδυνοι
    - Ατέρμονοι βρόχοι: Π.χ `married(X,Y) :- married(Y,X)` -> Λύση: `marriedToEachother(X,Y) :- married(X,Y); married(Y,X)`

## Αναδρομή (Recursion)
- Βασική αρχή: Χρήση μαθηματικής επαγωγής με:
    - **Τερματική συνθήκη**: Βασική περίπτωση (π.χ `factorial(0,1)`)
    - **Αναδρομική κλήση**: Κλήση του ίδιου κατηγορήματος με απλούστερο όρισμα (π.χ `factorial(N,F) :- N > 0, N1 is N - 1, factorial(N1,F1), F is N * F1`)
- Προσοχή: Η σειρά των κανόνων είναι κρίσιμη για την αποφυγή ατέρμονων βρόχων

## Λίστες
- Σύνταξη: `[a,b,c]` ή `[H|T]` (κεφαλή `H` και ουρά `Τ`)
- Κατηγορήματα:
    - `member(X,L)`: Ελέγχει αν το `x` ανήκει στην λίστα `L`
    - `length(L,N)`: Επιστρέφει το μήκος `Ν` της λίστας `L`
    - `append(L1,L2,L3)`: Συνενώνει τις λίστες `L1` και `L2` στην `L3`
    - `reverse(L1,L2)`: Ανριστρέφει τη λίστα `L1` σε `L2`
- Παραδείγματα
    - Τελευταίο στοιχείο:
        ```prolog
        last_element([Laste],Last).
        last_element([_|T],Last) :- last_element(T,Last).
        ```
    - Άθροισμα στοιχείων
        ```prolog
        sum([],0).
        sum([H|T],S) :- sum(T,S1), S is H + S1
        ```

## Προγραμματιστικό Στυλ
- Σχόλια: Χρησιμοποιούνται με `%` για μονή γραμμή ή `\* ... *\` για πολλαπλές γραμμές
- Τεκμηρίωση κατηγορημάτων
    ```prolog
    %male_player/2
    %male_player(Team,Player): Succeeds if Player is a male member of Team
    male_player(Team,Player) :- player_of(Team,Player), male(Player)
    ```

## Συμβουλές για Αποδοτικό κώδικα
- Αποφυγή ατέρμονων βρόχων: Πάντα να ορίζετε πρώτα τις τερματικές συνθήκες
- Σωστή αναπαράσταση δεδομένων: Να επιλέγετε δομές που επιτρέπουν ευέλικτες ερωτήσεις (π.χ `belongs_to/2` αντί για πολλά κατηγορήματα)
- Βελτιστοποίηση αναδρομής: Χρήση προσωρινών μεταβλητών για αποδοτικότητα (π.χ `list_max2`)

## Τελεστές
- Τύποι Τελεστών
    - Προθεματικός (prefix): `fx` (π.χ `-5`)
    - Ενθεματικός (infix): `yfx` (π.χ `2 + 3`)
    - Επιθεματικός (postfix): `xf` (π.χ `5!`)
- Προτεραιότητα:
    - `*` έχει υψηλότερη προτεραιότητα από `+`
    - Παράδειγμα `2 + 3 * 5` <-> `+(2,*(3,5))`
- Ορισμός νέων τελεστών:
    ```prolog
    :- op(500,xfx,!).           % ορίζει τελεστή παραγοντικού
    N ! F :- factorial(N,F).    % Χρήση 4 ! result -> result = 24
    ```

## Υπολογισμός Αριθμιτικών Εκφράσεων
- `is/2` Υπολογίζει αριθμητικές εκφράσεις
    - Παράδειγμα
        ```prolog
        ?- X is 5 + 2.  % X = 7
        ?- 10 is 5 +5.  % true
        ```
    - Προσοχή
        - Το δεξί όρισμα πρέπει να είναι πλήρως ορισμένο (χωρίς ελέυθερες μεταβλητές)
        - `X is X + 1` είναι λάθος (αδύνατη λογική σχέση)
- Τελεστές Σύγκρισης:
    - `=`, `\=`, `==`, `=\=`, `>`, `<`, `>=`, `=<`
    - Παράδειγμα
        ```prolog
        ?- 5 \= 6.          % true
        ?- 5 + 2 =:= 3 + 4. % true
        ```

## Άρνηση (Negation)
- `\+` ή `not.1`: Βασίζεται στην "υπόθεση του κλειστού κόσμου"
    - Παράδειγμα
        ```prolog
        man(peter). woman(helen).
        ?- \+ man(helen)    % true (δεν μπορεί να αποδειχθεί)
        ?- \+ man(X)        % false (υπάρχει τουλάχιστον ένας άνδρας)
        ```
    - Προσοχή: Η σειρά των κανόνων επηρεάζει τα αποτελέσματα
        ```prolog
        ?- man(X), \+ woman(X).     % X = peter ; X = jimmy
        ?- \+ woman(X), man(X).     % false (λόγω σειράς εκτέλεσης)
        ```


## Ενοποίηση (Unification)
- Ορισμός: Διαδικασία ταιριάσματος δύο όρων με αντικαταστάσεις
- Κανόνες:
    1. Δύο σταθερές ενοποιούνται αν είναι ίδιες
    2. Μεταβλητή ενοποιείται με οποιονδήποτε όρο
    3. Σύνθετοι όροι ενοποιούνται αν έχουν ίδιο function και ενοποιήσιμα ορίσματα
- Παραδείγματα:
    ```prolog
    ?- foo(a,b) = foo(X,Y). % X = a, Y = b
    ?- [a,b,c] = [X|Y].     % X = a, Y = [b,c]
    ?- X = father(X)        % Ατέρμονη ενοποίηση (λάθος)
    ```

## Είδη Ισότητας
- `=`: Ενοποίηση όρων (χωρίς υπολογισμούς)
    ```prolog
    ?- 2 + 3 = +(2,3)   % true
    ```
- `==`: Αριθμητική ισότητα (με υπολογισμούς)
    ```prolog
    ?- 5 + 2 =:= 3 + 4  %true
    ```
- `is`: Υπολογίζει το δεξί όρισμα και το αντιστοιχεί στο αριστερό
    ```prolog
    ?- X is 5 + 2       % X = 7
    ```

## Σημαντικές Παρατηρήσεις
- Ατέρμονοι βρόχοι: Προκύπτουν από λανθασμένους αναδρομικούς ορισμούς (π.χ `X = father(X)`)
- Σειρά κανόνων: Η Prolog εκτελεί κανόνες από πάνω προς τα κάτω και subgoald από αριστερά προς τα δεξιά
- Μεταβλητές: Μία μεταβλητή μπορεί να πάρει μόνο μία τιμή (single assignment)

## Μηχανισμός Εκτέλεσης
- Βασική Αρχή: Η Prolog χρησιμοποιεί αναζήτηση κατά βάθος (DFS) και οπισθοδρόμηση (backtracking) για την επίλυση ερωτημάτων
    - Ενοποίηση (Unification): Προσπαθεί να ταιριάξει την ερώτηση με γεγονόντα ή κανόνες
    - Στοίβα Σημείων Οπισθοδρόμησης: Αποθυκέυει εναλλακτικές λύσεις για επαναληψη ανάγκης
- Παράδειγμα:
    ```prolog
    p(1).   p(2).
    ?- p(x), p(y).  % Επιστρέφει όλους του συνδυασμούς: X=1, Y=1 ... 
    ```

## Είσοδος/Έξοδος
- Βασικά Κατηγορήματα:
    - `read/1`: Διαβάζει όρο από την είσοδο
    - `write/1`: Γράφει όρο στην έξοδο
    - `n1/0`: Εκτυπώνει νέα γραμμή
- Παράδειγμα:
    ```prolog
    start :- 
        write('Enter a number: '),
        read(N),
        Square is N * N
        write('Square: '), write (Square), n1.
    ```

## Αρχεία
- Διαχείριση Αρχείων:
    - `see/1`: Ανοίγει αρχείο για ανάγνωση
    - `tell/1`: Ανοίγει αρχείο για εγγραφή
    - `seen/0`, `told/0`: Κλείνουν τα αρχεία
- Παράδειγμα
    ```prolog
    write_list([]).
    write_list([H|T]) :- write(H), nl, write_list(T).

    save_to_file(List) :-
        tell('output.txt'),
        write_list(List),
        told.
    ```

## Αποκοπή (Cut)
- Σύμβολο: `!` (κλαδέυει το δέντρο αναζήτησης)
- Χρήσεις:
    - Βελτιστοποίηση: Αποφυγή άσκοπων υπολογισμών
    - Έλεγχος Ροής: Αποφυγή εναλλακτικών λύσεων
- Παράδειγμα:
    ```prolog
    factorial(0, 1) :- !.  % Τερματική συνθήκη με αποκοπή.
    factorial(N, F) :-
        N > 0,
        N1 is N - 1,
        factorial(N1, F1),
        F is N * F1.
    ```

## Άρνηση ως Αποτυχία
- Κατηγόρημα `\+/1`: Επιστρέφει `true` αν ο στόχος δεν μπορεί να αποδειχθεί
- Παράδειγμα
    ```prolog
    not_member(X, []) :- !.
    not_member(X, [X|_]) :- !, fail.
    not_member(X, [_|T]) :- not_member(X, T).
    ```

## Πρόβλημα του Βοσκού
- Περιγραφή: Μεταφορά βοσκού, λύκου, προβάτου και σανού σε άλλη όχθη με περιορισμούς
- Αναπαράσταση Καταστάσεων:
    ```prolog
    state(shepherd(a), sheep(a), wolf(a), hey(a)).  % Αρχική κατάσταση.
    ```
- Κινήσεις:
    ```prolog
    move(state(shepherd(X), sheep(X), W, H), move_sheep, state(shepherd(Y), sheep(Y), W, H)) :-
        opposite(X, Y).
    ```
- Επίλυση:
    ```prolog
    solve(State, [], _) :- end_state(State).
    solve(State, [Move|Moves], Visited) :-
        move(State, Move, NextState),
        \+ member(NextState, Visited),
        is_valid(NextState),
        solve(NextState, Moves, [NextState|Visited]).
    ```

## Συμβουλές για Τελικό
- Κατανόηση Ενοποίησης: Κρίσιμη για την επίλυση ερωτημάτων
- Αποκοπή: Χρησιμοποιείται για βελτιστοποίηση, αλλά με προσοχή (κόκκινη vs πράσινη)
- Αναδρομή: Πάντα να ορίζετε τερματικές συνθήκες πρώτα
