# ΗΥ345 - Λειτουργικά Συστήματα
## Deadlocks

- **Ορισμός Deadlocks**
  Ένα σύνολο διεργασιών βρίσκεται σε αδιέξοδο αν κάθε διεργασία του συνόλου περιμένει ένα συμβάν που μόνο μια άλλη διεργασία του συνόλου μπορεί να προκαλέσει.
- **Συνθήκες Coffman**
  Οι τέσσερις συνθήκες που πρέπει να ισχύουν ταυτόχρονα για να προκύψει deadlock:
  1. Συνθήκη αμοιβαίου αποκλεισμού
    Κάθε πόρος είναι είτε εκχωρημένος σε μία ακριβώς διεργασία, είτε είναι διαθέσιμος
  2. Συνθήκη Δεσμευσης και αναμονής
    Διεργασίες που δεσμέυουν την τρέχουσα στιγμή πόρους που τους εκχωρήθηκαν νωρίτερα, μπορούν να ζητήσουν και άλλους
  3. Συνθήκη μη προεκτόπισης
    Πόροι που έχουν εκχωρηθεί σε μια διεργασία δεν μπορούν να αφαιρεθούν από αυτή με τη βία. Πρέπει η ίδια η διεργασία να τους αποδεσμέυσει.
  4. Συνθήκη κυκλικής αναμονής
    Πρέπει να υπάρχει μια κυκλική λίστα δύο ή περισσότερων διεργασιών, κάθε μία από τις οποίες περιμένει έναν πόρο τον οποίο κατέχει το επόμενο μέλος της αλυσίδας.
- **Μοντελοποίηση Deadlock**
  - Ένα τόξο που ξεκινάει από έναν πόρο (τετράγωνο) και καταλήγει σε μία διεργασία (κύκλο) σημαίνει ότι η διεργασία έχει ζητήσει τον πόρο, τον απέκτησε και την στιγμή αυτή τον κατέχει
  - Ένα τόξο που ξεκινάει από μία διεργασία προς ένα πόρο σημαίνει πως η διεργασία είναι μπλοκαρισμένη περιμένοντας για τον πόρο.
  - Φτιάχνουμε τον γράφο που δείχνει πώς συνδέονται οι πόροι με τις διεργασίες, **σε περίπτωση που δημιουργούνται κύκλοι στον γράφο σημαίνει ότι υπάρχει αδιέξοδος**.
- **Αντιμετώπιση Deadlocks**
  Γενικότερα για την αντιμετώπιση deadlocks χρησιμοποιούμε τέσσερις στρατηγικές:
  1. Αγνοούμε το πρόβλημα εντελώς
  2. Εντοπισμός και Ανάκαμψη
  3. Δυναμική Αποφυγή
  4. Αποτροπή
