## Αλγόριθμοι Divide & Conquer
### Maxima Set
Δοθέντος ενός συνόλου σημείων στο επίπεδο βρίσκει τα μη-κυριαρχούμενα σημεία, ένα σημείο $(x,y)$ κυριαρχείται αν υπάρχει άλλο σημείο $(x',y')$ με $x' \geq x$ και $y' \geq y$.
**Πολυπλοκότητα:** $O(n\log n)$

Είσοδος: Σύνολο $S$ με $n$ σημεία
Έξοδος: Σύνολο $M$ με τα *maxima points*
```
MaximaSet(S,n):
  if n <= 1:
    return S
  L <- left half
  R <- right half
  ML <- MaximaSet(L)
  MR <- MaximaSet(R)
  ymax <- max{ y : (x,y) in MR}
  remove all points from ML where y < ymax
  return (ML ++ MR)
```

### Merge Sort
Ταξινομεί έναν πίνακα, τον χωρίζει αρχικά στην μέση, ταξινομεί αναδρομικά τα δύο μισά και τα συγχωνέυει σε έναν ταξινομημένο.
**Πολυπλοκότητα:** $O(n\log n)$

Είσοδος: πίνακας $S$ me $n$ στοιχεία
Έξοδος: πίνακας $S$ ταξινομημένος
```
MergeSort(S,n):
  if n <= 1:
    return S
  S1, S2 <- partition(S,n/2)
  S1 <- MergeSort(S1,n/2)
  S2 <- MergeSort(S2,n/2)
  S <- Merge(S1,S2)
  return S

Merge(S1,S2):
  i <- 1
  j <- 1
  while i <= n and j <= n:
    if S1[i] <= S2[j]:
      S[i+j-1] <- S1[i]
      i++
    else 
      S[i+j-1] <- S2[j]
      j++

  while i <= n:
    S[i+j-1] <- S1[i]
    i++

  while j <= n:
    S[i+j-1] <- S2[j]
    j++
```

### Quick Sort
Ταξινομεί έναν πίνακα, διαλέγει ένα *pivot*, αναδιατάσσει τον πίνακα ώστε τα μικρότερα να πάνε αριστερά και τα μεγαλύτερα να πάνε δεξιά και ταξινομεί αναδρομικά τα δύο κομμάτια
**Πολυπλοκότητα:** Best/Average: $O(n\log n)$ Worst: $O(n^2)$
Στην πράξη είναι συχνά πιο γρήγορος από τον Merge Sort οπότε επιλέγεται συχνά.

Είσοδος: πίνακας $S$ με $n$ στοιχεία
Εξόδος: πίνακας $S$ ταξινομημένος

```
QuickSort(S,lo,hi):
  if lo >= hi:
    return S
  p <- partition(S,low,hi)
  QuickSort(S,lo,p-1)
  QuickSort(S,p+1,hi)

partition(S,lo,hi):
  pivot <- S[hi]
  i <- lo - 1
  for j <- lo to hi - 1:
    if S[j] <= pivot:
      i++
      swap(S[i],S[j])
  swap(S[i+1],S[hi])
  return i+1
```

### Quick Select
Βρίσκει το k-οστό μικρότερο στοιχείο ενός μη ταξινομημένου πίνακα χωρίς να τον ταξινομήσει. Χωρίζει σε partitions αλλά αντί να μπεί αναδρομικά και στα δύο κομμάτια μπαίνει μόνο σε αυτό το οποίο περιέχει το ζητούμε k.

**Πολυπλοκότητα:** Best/Average: $O(n)$ Worst: $O(n^2)$

Είσοδος: Πίνακας $S$ με $n$ στοιχεία, pivot $k$
Έξοδος: η θέση του κ-οστού μικρότερου στοιχείου μέσα στον πίνακα

```
QuickSelect(S,lo,hi,k):
  if lo <= hi:
    return A[lo]
  p <- RandPartition(S,lo,hi)
  m <- p - lo + 1
  
  if k == m: 
    return A[p]
  elif k < m:
    return QuickSelect(S,lo,p-1,k)
  else:
    return QuickSelect(S,p+1,hi,k-m)
```

## Αλγόριθμοι Ταξινόμησης σε γραμμικό χρόνο
### Bucket Sort
Αντί να συγκρίνει στοιχεία μεταξύ τους τα μοιράζει σε κάδους ανάλογα με την τιμή τους, στο τέλος περνάμε γραμμικά τους κάδους και πρόσθέτουμε κάθε στοιχείο τους.
**Πολυπλοκότητα:** $Ο(n+Ν)$

Είσοδος: πίνακας $S$ με $n$ στοιχεία στην περιοχή $[0,N-1]$
Έξοδος: πίνακας $S$ ταξινομημένος

```
BucketSort(S,n,Ν):
  B <- πίνακας Ν κενών λιστών
  for each e in S:
    k <- key of e
    αφαίρεσε e από S
    πρόσθεσε e στο τέλος τις λίστας B[k]
  for i <- 0 to N-1 do:
    for each entry e in B[i] do:
      αφαίρεσε e από το B[i]
      πρόσθεσε e στο τέλος του S
```

### Radix Sort
Ταξινομεί ακέραιους ψηφίο-ψηφίο χωρίς να συγκρίνει ολόκληρα κξλειδιά μεταξύ τους. Κάνει d περάσματα, ένα για κάθε ψηφίο, και σε κάθε πέρασμα ταξινομέι με βάση μόνο αυτό το ψηφίο χρησιμοποιόντας bucket sort.
**Πολυπλοκότητα:** $Ο(d(n+N))$

```
RadixSort(S,n,N):
  for i <- d downto 1:
    BucketSort(S,n,N)
```

## Greedy Αλγόριθμοι
### Fractional Knapsack
Έχουμε $n$ αντικείμενα, το κάθε ένα με βάρος $w_i$ και αξία $b_i$ και σακίδιο χωρητικότητας $W$, θέλουμε να μεγιστοποιήσουμε την αξία που μπορούμε να βάλουμε μέσα στο σακίδιο. Παίρνουμε κλάσματα των αντικειμένων ώστε να μεγιστοποιήσουμε την συνολική αξία και διαλέγουμε πάντα ότι έχει την καλύτερη απόδοση ανά βάρος.
**Πολυπλοκότητα:** $O(n\log n)$ 

Είσοδος: πίνακας $S$ με $n$ στοιχεία με βάρος $w_i$ και αξία $b_i$ και ένα μέγιστο βάρος $W$
Έξοδος: Μέγιστο υποσύνολο από S με βάρος το πολύ $W$

```
FractionalKnapsack(S,n,W,b,w):
  for each i in S:
    v[i] <- b[i] / w[i]
  
  ταξινομούμε το S κατά φθίνουσα σειρά

  total <- 0
  cap <- W

  for i <- 1 to n:
    if cap == 0:
      break
    x <- min{ w[i], cap } 
    total += x * v[i]
    cap -= x
  
  return total
```

## Huffman
Φτιάχνει βέλτιστο κώδικα προθέματος για συμπίεση. Δίνει κοντά codewords στους συχνούς χαρακτήρες και μακριά στου σπάνιους ελαχιστοποιόντας το συνολικό μήκος.
**Πολυπλοκότητα:** $O(n \log n)$

Είσοδος: αλφαριθμιτικός $X$ μεγέθους $n$ και $d$ χαρακτήρες 
Έξοδος: κωδικοποιημένο δέντρο για τον $X$

```
Huffman(C):
  Q <- min heap με όλους τους χαρακτήρες

  for i <- 1 to n-1:
    x <- ExtractMin(Q)
    y <- ExtractMin(Q)

    z <- νέος κόμβος
    z.left <- x
    z.right <- y
    z.f <- x.f + y.f

    Insert(Q,z)
  
  return ExtractMin(Q)  // η ρίζα του δέντρου
```

## Dynamic Programming
### matrixChain
Ο πολλαπλασιασμός μιας αλυσίδα πινάκων $A_1 \cdot A_2 \cdot ... \cdot A_n$ είναι προσεταιριστικός, το αποτέλεσμα δεν αλλάζει με όποια σειρά και ας κάνουμε τους πολλαπλασιασμόύς αλλά το κόστος αλλάζει δραματικά. Θέλουμε να βρούμε την παρενθεσοποίηση με το ελάχιστο πλήθος βαθμωτών πολλαπλασιασμών.
Το κόστος ενός πολλαπλασιασμού πινάκων $p \times q$ και $q \times r$ είναι $p \cdot q \cdot r$.
**Πολυπλοκότητα:** $O(n^3)$

Είσοδος: ένας πίνακας $p$ μεγέθους $n$ όπου ο $A_i$ έχει διάσταση $p[i-1] \times p[i]$

```
MatrixChainMult(p,n):
  m <- πίνακας n x n
  s <- πίνακας n x n

  for i <- 1 to n:
    m[i][i] <- 0
  
  for L <- 2 to n:
    for i <- 1 to n - L + 1:
      j <- i + L - 1
      m[i][i] <- infty
  
      for k <- i to j-1:
        q <- m[i][k] + m[k+1][j] + p[i-1] * p[k] * p[j]
        if q < m[i][j]:
          m[i][j] <- q
          s[i][j] <- k
  
  return m[1][n]
```

### Longest Common Subsequence
Βρίσκει την μεγαλύτερη κοινή υποακολουθία σε δυο ακολουθίες διαφορετικού μεγέθους
**Πολυπλοκότητα:** $O(n \cdot m)$

Είσοδος: δύο αλφαριθμητικοί και τα ανάλογα μεγέθη τους
Έξοδος: η μεγαλύτερη υποακολουθία και των δύο αλφαριθμητικών εισόδων

```
LCS(X,Y,n,m):
  c <- πίνακας (n+1)x(m+1) 

  for i <- 0 to n: c[i][0] <- 0
  for j <- 0 to m: c[0][j] <- 0

  for i <- 1 to n:
    for j <- 1 to m:
      if X[i] = Y[i]:
        c[i][j] <- c[i-1][j-1] + 1
      else:
        c[i][j] <- max{ c[i-1][j], c[i][j-1] }
  
  return c[n][m]
```

### 0/1 Knapsack
Όπως και το κανονικό knapsack αλλά αυτή την φορά δεν μπορούμε να πάρουμε κομμάτι από ένα αντικείμενο, το παίρνουμε όλο ή καθόλου.
**Πολυπλοκότητα:** $O(n \cdot w)$

Είσοδος: πίνακας $S$ με $n$ στοιχεία με βάρος $w_i$ και αξία $b_i$ και ένα μέγιστο βάρος $W$
Έξοδος: Μέγιστο υποσύνολο από S με βάρος το πολύ $W$

```
Knapsack01(S,n,W,w,b):
  V <- πίνακας (n+1)x(W+1)

  for i <- 0 to W: V[0][i] <- 0
  for j <- 0 to n: V[j][0] <- 0

  for i <- 1 to n:
    for j <- 1 to W:
      if w[i] > j:
        V[i][j] <- V[i-1][j]  
      else:
        V[i][j] <- max{V[i-1][j], V[i-1][j-w[i]] + b[i]}
  
  return V[n][W]
```

Βρίσκει τις συντομότερες διαδρομές από μια πηγή s προς όλους του κόμβους ενός γράφου με μη-αρνητικά βάρη ακμών. 
**Πολυπλοκότητα:** Πίνακας: $O(V^2)$, Binary min-heap: $O((V+E) \log V)$, Fibonacci heap: $O(E + V \log V)$

Είσοδος:
Έξοδος:

```
Dijkstra(G,w,s):
  for each v in V:
    d[v] <- infty
    π[v] <- NULL
  d[s] <- 0

  S <- {}
  Q <- min-heap με όλους τους v

  while Q != {}:
    u <- ExtractMin(Q)
    S <- S ++ {u}
    
    for each v γείτονας του u:
      if d[v] > d[u] + w(u,v):
        d[v] <- d[u] + w(u,v)
        π[v] <- u
        DecreaseKey(Q,v,d[v])
  
  return d,π
```

### Bellmand-Ford
Επίσης βρίσκει τις συντομότερες διαδρομές αλλά λειτουργεί και για αρνητικά βάρη, λίγο πιο ακριβός χρονικά.
**Πολυπλοκότητα:** $O(V \cdot E)$

```
BellmanFord(G,w,s):
  for each v in V:
    d[v] <- infty
    π[v] <- NULL
  d[s] <- 0

  for i <- 1 to |V| - 1:
    for each (u,v) in E:
      if d[u] + w(u,v) < d[v]:
        d[v] <- d[u] + w(u,v)
        π[v] <- u
      
  for each (u,v) in E:
    if d[u] + w(u,v) < d[v]:
      return "Αρνητικός κύκλος"
  
  return d,π
```

### MST
MST (Minimum Spanning Tree) είνα το spanning tree με το ελάχιστο συνολικό βάρος, συγκεκριμμένα είναι ένας υπόγραφος που:
- περιέχει όλους του $V$ κόμβους
- είναι δέντρο 
- έχει ακριβώς $V-1$ ακμές

Για να βρούεμ το MST από ένα δέντρο έχουμε δύο αλγορίθμους:
**PRIM MST**
Ξεκινάμε από έναν κόμβο και μεγαλώνουμε ένα δέντρο, σε κάθε βήμα προσθέτουμε την ελαφρήερη ακμή που βγάζει από το δέντρο προς τα έξω.

```
Prim(G,w,r):
  for each v: 
    key[v] <- infty
    π[v] <- NULL
  key[r] <- 0
  Q <- min-heap όλων με κλειδί key

  while Q != {}:
    u <- ExtractMin(Q)
    for each γειτονα v του u:
      if v in Q and w(u,v) < key[v]:
        key[v] <- w(u,v)
        π[v] <- u
        DecreaseKey(Q,v,key[v])
```

**Kruskal MST**
Ταξινομούμε όλες τις ακμές και παίρνουμε κάθε φορά την φθηνότερη εκτός άμα αυτή κλείνει κύκλο

```
Kruskal(G,w):
  A <- {}
  for each v:
    MakeSet(V)
  
  ταξινομούμε τις ακμές κατά αυξον ρυθμό

  for each (u,v) με αυτή την σειρά:
    if FindSet(u) != FindSet(v):
      A <- A ++ {(u,v)}
      Union(u,v)
  
  return A
```
