# ΗΥ345 - Λειτουργικά Συστήματα
## Εικονική Μνήμη

- **Εικονική Μνήμη**
  Η βασική ιδέα πίσω από την εικονική μνήμη είναι ότι κάθε πρόγραμμα έχει τον δικό του χώρο διευθύνσεων, ο οποίος διαιρείται σε μικρά κομμάτια που ονομάζονται σελίδες όπου κάθε σελίδα είναι ένα συνεχές εύρος διευθύνσεων. Οι σελίδες αυτές μετά χαρτογραφούνται μέσα στην φυσική μνήμη αλλά δεν χρειάζεται να βρίσκονται όλες οι σελίδες ταυτόχρονα στην μνήμη, μπορούν μερικές που δεν χρειάζονται την δεδομένη στιγμή να είναι στον δίσκο για να σώσουν χώρο μέσα στην κύρια μνήμη. Κάθε φορά που το πρόγραμμα αναφέρεται σε ένα τμήμα του χώρου διευθύνσεων το υλικό εκτέλεί την απαραίτητη χαρτοχράφηση επιτόπου.
  Έτσι κερδίζουμε:
  - οι διεργασίες προστατευονται η μία από την άλλη
  - μπορούμε να γεμίσουμε κενά στην μνήμη πιο αποδοτικά
  - μπορούμε να τρέξουμε προγράμματα ακόμα και αν δεν αρχεί η μνήμη
- **Σελιδοποίηση**
  Η σελιδοποίηση είναι τεχνική διαχείρισης μνήμης που χωρίζει τόσο τη λογική (εικονική) μνήμη όσο και τη φυσική μνήμη σε σταθερού μεγέθους μπλοκ, τις σελίδες (pages) και τα frames αντίστοιχα. Κάθε σελίδα μιας διεργασίας μπορεί να τοποθετηθεί σε οποιοδήποτε διαθέσιμο frame στη φυσική μνήμη, χωρίς να χρειάζεται συνεχόμενο block. Το σύστημα κρατά έναν πίνακα σελίδων (page table) που χαρτογραφεί κάθε εικονική σελίδα στο αντίστοιχο φυσικό frame. Οφέλη:
  - Αποφεύγεται ο εξωτερικός κατακερματισμός μνήμης
  - Διεργασίες μπορούν να φορτώνονται τμηματικά και να εκτελούνται χωρίς να χρειάζεται ολόκληρη η μνήμη τους
  - Η διαχείριση μνήμης γίνεται πιο ευέλικτη και ασφαλής, αφού κάθε διεργασία βλέπει τον δικό της χώρο διευθύνσεων
- **Πίνακες Σελίδας**
  Ο πίνακας σελίδας (page table) είναι δομή δεδομένων που χρησιμοποιεί το σύστημα για να μεταφράζει τις εικονικές διευθύνσεις σε φυσικές. Κάθε είσοδος δείχνει σε ποιο frame της φυσικής μνήμης βρίσκεται η αντίστοιχη σελίδα της διεργασίας. Με αυτόν τον τρόπο, οι διεργασίες μπορούν να χρησιμοποιούν ανεξάρτητους χώρους διευθύνσεων χωρίς να επηρεάζονται μεταξύ τους.
- **Πολυεπίπεδοι Πίνακες Σελίδας**
  Οι πίνακες σελίδας πολλαπλών επιπέδων (multi-level page tables) χωρίζουν τον πίνακα σελίδας σε ιεραρχικά επίπεδα για εξοικονόμηση μνήμης. Αντί να υπάρχει ένας τεράστιος πίνακας για όλη την εικονική μνήμη, χρησιμοποιούνται πίνακες δευτέρου (ή τρίτου) επιπέδου μόνο για τις περιοχές που πραγματικά χρησιμοποιούνται. Έτσι μειώνεται ο χώρος που καταλαμβάνει ο πίνακας σελίδας και διατηρείται γρήγορη η μετάφραση διευθύνσεων.
- **Ανεστραμμένος Πίνακας Σελίδων**
  Ο αντεστραμμένος πίνακας σελίδων (inverted page table) κρατά ένα entry ανά frame φυσικής μνήμης αντί για κάθε σελίδα εικονικής μνήμης. Κάθε entry περιέχει ποια διεργασία και ποια σελίδα χρησιμοποιεί το συγκεκριμένο frame, μειώνοντας δραστικά τον χώρο για μεγάλες διεργασίες. Η μετάφραση διευθύνσεων γίνεται με αναζήτηση στον πίνακα (συνήθως με hash), αντί για άμεση πρόσβαση όπως στους κανονικούς πίνακες σελίδας.
- **Σφάλμα Σελίδας**
  Το σφάλμα σελίδας (page fault) συμβαίνει όταν μια διεργασία προσπελάζει μια σελίδα που δεν είναι στη φυσική μνήμη. Τότε το λειτουργικό φορτώνει τη σελίδα από τον δίσκο σε ένα διαθέσιμο frame, ενημερώνει τον πίνακα σελίδων και συνεχίζει την εκτέλεση της διεργασίας. Είναι φυσιολογικό φαινόμενο στην εικονική μνήμη και καθορίζει πόσο συχνά η διεργασία χρειάζεται πρόσβαση σε δίσκο.
- **Αντικατάσταση Σελίδας**
  Η αντικατάσταση σελίδας (page replacement) είναι η διαδικασία επιλογής μιας σελίδας στη φυσική μνήμη για απομάκρυνση όταν χρειάζεται να φορτωθεί μια νέα σελίδα και δεν υπάρχουν ελεύθερα frames. Το λειτουργικό χρησιμοποιεί αλγορίθμους όπως FIFO, LRU ή Optimal για να αποφασίσει ποια σελίδα θα αντικατασταθεί ώστε να μειωθούν τα σφάλματα σελίδας.
- **TLB**
  Η TLB (Translation Lookaside Buffer) είναι μια μικρή, γρήγορη μνήμη cache που κρατά συχνά χρησιμοποιούμενες καταχωρήσεις πίνακα σελίδων. Χρησιμοποιείται για να επιταχύνει τη μετάφραση εικονικών → φυσικών διευθύνσεων, μειώνοντας τα ακριβά προσπελάσματα στη RAM.
