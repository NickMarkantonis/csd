To compile and run verilog files:
1. Create a file with a ".v" extension and write your code inside it
2. Make sure you have iverilog installed, to do so in bash run:
  sudo apt update
  sudo apt install iverilog
3. To compile the code run the command:
  iverilog -o outputFile_tb sourceCodeFile.v
4. Lastly to run the code run the command:
  vvp example_tb
