# ΗΥ345 - Λειτουργικά Συστήματα
## Προβλήματα Συγχρονισμού

- **Πρόβλημα καταναλωτή-παραγωγού**
  **Πρόβλημα:**
  - Υπάρχει ένας καθολικός buffer με πεπερασμένο μέγεθος.
  - Ο παραγωγός (producer) παράγει δεδομένα και τα βάζει στον buffer.
  - Ο καταναλωτής (consumer) παίρνει δεδομένα από τον buffer.

  **Προβλήματα που προκύπτουν:**
  - Ο παραγωγός δεν μπορεί να προσθέσει αν ο buffer είναι γεμάτος.
  - Ο καταναλωτής δεν μπορεί να πάρει αν ο buffer είναι άδειος.
  - Αν η πρόσβαση στον buffer δεν προστατευτεί, μπορεί να προκύψει race condition.
  
  **Λύση:**
  - Χρησιμοποιούνται mutexes για τον αποκλεισμό πρόσβασης στον buffer.
  - Χρησιμοποιούνται semaphores για να παρακολουθούνται οι θέσεις:
    - empty → αριθμός κενών θέσεων
    - full → αριθμός γεμάτων θέσεων
  - Ο producer περιμένει αν empty == 0, ο consumer περιμένει αν full == 0.
- **Πρόβλημα αναγνωστών-γραφέων**
  **Πρόβλημα:**
  - Υπάρχει μια κοινή βάση δεδομένων.
  - Οι αναγνώστες (readers) μπορούν να διαβάζουν ταυτόχρονα χωρίς πρόβλημα.
  - Οι συγγραφείς (writers) χρειάζονται αποκλειστική πρόσβαση για να γράψουν.

  **Προβλήματα που προκύπτουν:**
  - Αν όλοι οι πόροι πάνε στους writers, οι readers μπορεί να μείνουν για πάντα αποκλεισμένοι (starvation).
  - Αν όλοι οι readers πάνε πρώτοι, οι writers μπορεί να περιμένουν επ’ αόριστον.

  **Λύση:**
  - Χρησιμοποιούνται mutexes και counters για να μετράμε πόσοι readers είναι ενεργοί.
  - Ο writer αποκτά αποκλειστικό lock πριν γράψει.
  - Υπάρχουν διάφορες στρατηγικές:
  - Readers-preference: προτεραιότητα στους αναγνώστες → μπορεί να προκαλέσει starvation στους writers.
  - Writers-preference: προτεραιότητα στους writers → μπορεί να καθυστερούν οι readers.
  - Fair solution: χρησιμοποιείται queue ή semaphore για να αποφεύγεται η αδικαιολόγητη αναμονή.
- **Πρόβλημα Δείπνου των φιλόσοφων**
  **Πρόβλημα:**
  - Πέντε φιλόσοφοι κάθονται γύρω από ένα τραπέζι με πέντε πιρούνια (ένα ανάμεσα σε κάθε δύο).
  - Κάθε φιλόσοφος εναλλάσσεται μεταξύ σκέψης και φαγητού.
  - Για να φάει, χρειάζεται δύο πιρούνια (αριστερά και δεξιά).
  
  **Προβλήματα που προκύπτουν:**
  - Αν όλοι σηκώσουν το αριστερό πιρούνι ταυτόχρονα, θα προκύψει deadlock.
  - Αν δεν υπάρχει σωστή στρατηγική, μπορεί να συμβεί starvation.
  
  **Λύση:**
  - Χρησιμοποιούνται mutexes για κάθε πιρούνι.
  - Στρατηγικές για αποφυγή deadlock:
  - Αριθμημένη προτεραιότητα: ο ένας φιλόσοφος παίρνει πρώτα δεξί, οι άλλοι αριστερό.
  - Μέγιστος αριθμός φιλοσόφων ταυτόχρονα στο τραπέζι < αριθμός πιρουνιών.
  - Resource hierarchy solution: όλοι οι φιλόσοφοι παίρνουν τα πιρούνια με συγκεκριμένη σειρά (π.χ. πάντα πρώτα το μικρότερο, μετά το μεγαλύτερο).
