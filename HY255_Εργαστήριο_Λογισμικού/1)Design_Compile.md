### Μεταβλητές
Περιέχουν δεδομένα του προγράμματος, κάθε μεταβλητή έχει έναν τύπο ο οποίος ορίζει:
1. Το μέγεθος της μεταβλητής 
2. Τις πράξεις που μπορούμε να κάνουμε 

Οι βασικές μεταβλητές και το μέγεθος που συνήθως είναι:
| type | size || type | size |
| - | - | - | - | - | 
| `char` | 1 || `long` | 8 |
| `int` | 4 || `float` | 4 |
| `short` | 2 || `double` | 8 |
