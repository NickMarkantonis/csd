### Τι είναι Dynamic Programming

Ο _Dynamic Programming_ (DP) λύνει προβλήματα **σπάζοντάς τα σε υποπροβλήματα**, αποθηκεύοντας τις λύσεις τους ώστε να μην τα ξαναλύνει.

Για να εφαρμοστεί DP, το πρόβλημα πρέπει να έχει δύο ιδιότητες:

- **_Optimal Substructure_**: η βέλτιστη λύση του προβλήματος αποτελείται από βέλτιστες λύσεις υποπροβλημάτων.
- **_Overlapping Subproblems_**: τα ίδια υποπροβλήματα εμφανίζονται επανειλημμένα — αξίζει να τα αποθηκεύουμε.

_Διαφορά με Divide & Conquer_: στο D&C τα υποπροβλήματα είναι **ανεξάρτητα** (π.χ. Merge Sort). Στο DP **επικαλύπτονται** — χωρίς αποθήκευση θα τα λύναμε εκθετικά πολλές φορές.

_Διαφορά με Greedy_: το Greedy κάνει μία τοπικά βέλτιστη επιλογή χωρίς να εξετάζει όλες τις εναλλακτικές. Το DP εξετάζει **όλα** τα υποπροβλήματα και διαλέγει βέλτιστα.



### Μεθοδολογία

Κάθε DP λύση ακολουθεί τα ίδια βήματα:

1. **Ορισμός υποπροβλήματος**: τι αποθηκεύουμε στον πίνακα $dp[i]$ ή $dp[i][j]$;
2. **Αναδρομική σχέση** _(recurrence)_: πώς υπολογίζεται το $dp[i][j]$ από μικρότερα υποπροβλήματα;
3. **Βάση**: τιμές για τις μικρότερες περιπτώσεις (συνήθως $dp[i][i]$ ή $dp[0][\cdot]$).
4. **Σειρά υπολογισμού**: υπολόγισε πρώτα τα μικρά, μετά τα μεγάλα.
5. **Ανακατασκευή λύσης** _(traceback)_: κράτα ποιες επιλογές έγιναν σε κάθε βήμα.



### Matrix Chain Multiplication

**Πρόβλημα**: δοθέντων $n$ πινάκων $A_1, A_2, \ldots, A_n$ με διαστάσεις $p_0 \times p_1,\ p_1 \times p_2,\ \ldots,\ p_{n-1} \times p_n$, βρες την **βέλτιστη παρενθετοποίηση** για τον υπολογισμό του γινομένου $A_1 \cdot A_2 \cdots A_n$ με ελάχιστο κόστος (πλήθος πολλαπλασιασμών).

_Κόστος_ πολλαπλασιασμού $(p \times q) \cdot (q \times r) = p \cdot q \cdot r$ πράξεις.

#### Ορισμός υποπροβλήματος

$m[i][j]$ = ελάχιστο κόστος για τον υπολογισμό του $A_i \cdot A_{i+1} \cdots A_j$.

#### Αναδρομική σχέση

$$m[i][j] = \min_{i \leq k < j} \Big( m[i][k] + m[k+1][j] + p_{i-1} \cdot p_k \cdot p_j \Big)$$

Η ιδέα: το τελευταίο «σπάσιμο» γίνεται στη θέση $k$ — πολλαπλασιάζουμε $(A_i \cdots A_k) \cdot (A_{k+1} \cdots A_j)$.

#### Βάση

$$m[i][i] = 0 \quad \text{(ένας πίνακας, κόστος μηδέν)}$$

#### Ψευδοκώδικας

```
MatrixChain(p, n):               // p[0..n] οι διαστάσεις
    for i = 1 to n: m[i][i] = 0
    for len = 2 to n:            // μήκος αλυσίδας
        for i = 1 to n-len+1:
            j = i + len - 1
            m[i][j] = +inf
            for k = i to j-1:
                cost = m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j]
                if cost < m[i][j]:
                    m[i][j] = cost
                    s[i][j] = k  // αποθήκευσε το βέλτιστο k
    return m[1][n]
```

$$ \boxed{\Theta(n^3) \text{ χρόνος}, \quad \Theta(n^2) \text{ χώρος}} $$

**Τύπος αλγορίθμου**: Dynamic Programming — optimal substructure (βέλτιστο σπάσιμο αποτελείται από βέλτιστα σπασίματα των δύο μερών) + overlapping subproblems (τα ίδια $m[i][j]$ χρειάζονται από πολλά μεγαλύτερα υποπροβλήματα).

#### Ανακατασκευή βέλτιστης παρενθετοποίησης

```
PrintOptimal(s, i, j):
    if i == j: print "A_i"
    else:
        print "("
        PrintOptimal(s, i, s[i][j])
        PrintOptimal(s, s[i][j]+1, j)
        print ")"
```

#### Παράδειγμα — JUNE22.4

$A_{30\times50},\ B_{50\times10},\ \Gamma_{10\times30},\ \Delta_{30\times50},\ E_{50\times30}$, δηλαδή $p = [30, 50, 10, 30, 50, 30]$.

Βέλτιστη παρενθετοποίηση: $\big((A \cdot B) \cdot ((\Gamma \cdot \Delta) \cdot E)\big)$

$$ \boxed{m[1][5] = 54000 \text{ πολλαπλασιασμοί}} $$

### 0-1 Knapsack

**Πρόβλημα**: $n$ αντικείμενα με βάρος $w_i$ και αξία $v_i$, χωρητικότητα $W$. Κάθε αντικείμενο παίρνεται **0 ή 1 φορά**. Μεγιστοποίησε τη συνολική αξία χωρίς να υπερβείς το $W$.

#### Ορισμός υποπροβλήματος

$K[i][w]$ = μέγιστη αξία χρησιμοποιώντας τα πρώτα $i$ αντικείμενα με χωρητικότητα $w$.

#### Αναδρομική σχέση

$$K[i][w] = \begin{cases} K[i-1][w] & \text{αν } w_i > w \quad \text{(δεν χωράει)} \\ \max\Big(K[i-1][w],\ v_i + K[i-1][w - w_i]\Big) & \text{αλλιώς} \end{cases}$$

#### Βάση

$$K[0][w] = 0 \quad \forall w, \qquad K[i][0] = 0 \quad \forall i$$

#### Ψευδοκώδικας

```
Knapsack01(v, w, n, W):
    for i = 0 to n: K[i][0] = 0
    for w = 0 to W: K[0][w] = 0
    for i = 1 to n:
        for w = 1 to W:
            if w[i] > w:
                K[i][w] = K[i-1][w]
            else:
                K[i][w] = max(K[i-1][w], v[i] + K[i-1][w - w[i]])
    return K[n][W]
```

$$ \boxed{\Theta(nW) \text{ χρόνος}, \quad \Theta(nW) \text{ χώρος}} $$

**Πολυπλοκότητα στη γενική περίπτωση**: το $\Theta(nW)$ είναι **ψευδο-πολυωνυμικό** — πολυωνυμικό στην _τιμή_ $W$ αλλά εκθετικό στο _μέγεθος_ της εισόδου ($\log W$ bits). Το 0-1 Knapsack είναι **NP-complete** (βλ. κεφάλαιο 6).



### Fractional vs 0-1 Knapsack

| | Fractional | 0-1 |
|-|-|-|
| Επιτρέπεται κλάσμα; | ✅ | ❌ |
| Αλγόριθμος | Greedy ($v_i/w_i$) | DP |
| Πολυπλοκότητα | $\Theta(n \log n)$ | $\Theta(nW)$ |
| Κλάση | P | NP-complete |

_Γιατί ο greedy αποτυγχάνει στο 0-1_: δεσμεύει χώρο με αντικείμενο υψηλού λόγου που μπορεί να αφήνει «νεκρό» χώρο, ενώ συνδυασμός φθηνότερων αντικειμένων θα έδινε μεγαλύτερη συνολική αξία.



### Bellman-Ford ως DP

Ο Bellman-Ford (κεφάλαιο 4) είναι ουσιαστικά **DP πάνω στον γράφο**:

$d^{(k)}[v]$ = συντομότερο μονοπάτι από $s$ στο $v$ με **ακριβώς** $\leq k$ ακμές.

$$d^{(k)}[v] = \min\Big(d^{(k-1)}[v],\ \min_{(u,v) \in E}\{ d^{(k-1)}[u] + w(u,v) \}\Big)$$

Βάση: $d^{(0)}[s] = 0$, $d^{(0)}[v] = +\infty$ για $v \neq s$. Μετά από $|V|-1$ γύρες (= $|V|-1$ «επίπεδα» DP) έχουμε τα τελικά αποτελέσματα.



### Longest Path σε DAG ως DP

Ο αλγόριθμος longest path σε DAG (κεφάλαιο 4) είναι επίσης DP:

$$\text{dist}[v] = \max_{(u,v) \in E} \{ \text{dist}[u] + w(u,v) \}$$

Η τοπολογική σειρά εγγυάται ότι όταν υπολογίζουμε $\text{dist}[v]$, όλα τα $\text{dist}[u]$ για $(u,v) \in E$ είναι ήδη τελικά.



### Πότε ΔΕΝ χρησιμοποιούμε DP

- Αν το πρόβλημα **δεν** έχει optimal substructure → DP δεν δίνει βέλτιστο.
- Αν τα υποπροβλήματα **δεν** επικαλύπτονται → D&C αρκεί (DP θα ήταν υπερβολικό).
- Αν υπάρχει **greedy** με αποδεδειγμένη ορθότητα → πάντα πιο γρήγορο από DP.



### Συνοπτικός Πίνακας

| Πρόβλημα | Υποπρόβλημα | Recurrence | Πολυπλοκότητα |
|-|-|-|-|
| Matrix Chain | $m[i][j]$: κόστος $A_i \cdots A_j$ | $\min_k(m[i][k] + m[k+1][j] + p_{i-1}p_kp_j)$ | $\Theta(n^3)$ |
| 0-1 Knapsack | $K[i][w]$: max αξία με $i$ αντικείμενα, χωρητικότητα $w$ | $\max(K[i-1][w],\ v_i + K[i-1][w-w_i])$ | $\Theta(nW)$ |
| Bellman-Ford | $d^{(k)}[v]$: min απόσταση με $\leq k$ ακμές | $\min(d^{(k-1)}[v],\ \min_{u} d^{(k-1)}[u] + w)$ | $\Theta(VE)$ |
| Longest Path DAG | $\text{dist}[v]$: μέγιστη απόσταση από $s$ | $\max_{(u,v)} \text{dist}[u] + w(u,v)$ | $\Theta(V+E)$ |
