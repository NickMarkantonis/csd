Καλώς ήρθατε στο repository με τις σημειώσεις μου για το Τμήμα Επιστήμης Υπολογιστών (CSD). 

## 🔗 Τρόποι Πρόσβασης

Συνιστάται να κατεβάζετε και να διαβάζετε τα αρχεία τοπικά μέσω εφαρμογής που υποστηρίζει σωστά το Markdown και LaTeX (το VScode έχει πολλά τέτοια extensions), καθώς το GitHub δεν υποστηρίζει καλά την μορφοποίηση LaTeX.

## 📥 Λήψη των Αρχείων
Μπορείτε να:
- Πατήσετε "Code" > "Download ZIP", ή
- Εκτελέσετε:
```bash
git clone https://github.com/NickMarkantonis/csd.git
```
Η δεύτερη επιλογή είναι καλύτερη αν θέλετε να κρατάτε τις σημειώσεις ενημερωμένες καθώς με `git pull` τραβάτε εύκολα τις νέες αλλαγές.

## ℹ️  Σημαντικές Πληροφορίες:

📌 Οι σημειώσεις αυτές είναι βοηθητικές και δεν αντικαθιστούν το υλικό που διδάσκεται από τους καθηγητές στο μάθημα. Είναι σχεδιασμένες για να διαβάζονται παράλληλα με το επίσημο υλικό του μαθήματος.

📌 Ενδέχεται να περιέχουν λάθη ή παραλείψεις. Αν εντοπίσετε κάτι, μπορείτε να ανοίξετε ένα issue, ή να προτείνετε αλλαγή με pull request.

📌 Δεν φέρω καμία ευθύνη για τυχόν ελλείψεις/λάθη στις σημειώσεις που μπορεί να οδηγήσουν σε αποτυχία σε κάποιο μάθημα ή χαμηλή βαθμολογία. Η χρήση τους γίνεται με δική σας ευθύνη.

📌 Οι σημειώσεις ανανεώνονται συνεχώς με την προσθήκη νέων αρχείων για τα μαθήματα, ώστε να είναι όσο το δυνατόν πιο ενημερωμένες.

## 💡 Πώς να Συνεισφέρετε
Θα χαρώ αν βοηθήσετε στη βελτίωση των σημειώσεων — είτε διορθώνοντας λάθη, είτε προσθέτοντας πιο καθαρές ή πιο σωστά διατυπωμένες εκδοχές.

Ειδικά ζητούμενο: Αν κάποιος έχει χρόνο και όρεξη να καθαρογράψει τις σημειώσεις της Γραμμικής Άλγεβρας σε Markdown, είναι πολύ ευπρόσδεκτο.

Οδηγίες για Pull Request:
1. Κάντε fork το repository.
2. Δημιουργήστε νέο branch για τις αλλαγές σας.
3. Κάντε commit και push τις αλλαγές σας.
4. Υποβάλετε pull request με σαφή περιγραφή των αλλαγών.

🎖️ Όσοι συμβάλλουν θα αναφέρονται στο repository ως contributors (credits), εφόσον το επιθυμούν.
