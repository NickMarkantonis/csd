### Το Πρόβλημα Ταξινόμησης

**Είσοδος**: ακολουθία $n$ στοιχείων $A[1..n]$.
**Έξοδος**: αναδιάταξη των στοιχείων σε αύξουσα (ή φθίνουσα) σειρά.

Διακρίνουμε δύο κατηγορίες αλγορίθμων:
- **_Comparison-based_**: συγκρίνουν ζεύγη στοιχείων με `<`, `>`. Κάτω φράγμα $\Omega(n \log n)$ (βλ. §2.6).
- **_Non-comparison_**: εκμεταλλεύονται ιδιότητες των δεδομένων (π.χ. εύρος τιμών) — μπορούν να σπάσουν το $\Omega(n \log n)$.



### Merge Sort

Κλασικό _Divide and Conquer_: διαίρεσε στη μέση, ταξινόμησε αναδρομικά, ένωσε τα δύο ταξινομημένα μισά.

```
MergeSort(A, p, r):
    if p >= r: return
    mid = (p + r) / 2
    MergeSort(A, p, mid)
    MergeSort(A, mid+1, r)
    Merge(A, p, mid, r)       // Θ(n) — σαρώνει και τα δύο μισά
```

Recurrence: $T(n) = 2T(n/2) + \Theta(n)$ → Master Theorem case 2 → $\boxed{\Theta(n \log n)}$ σε όλες τις περιπτώσεις.

_Παρατήρηση_: το Merge χρειάζεται $\Theta(n)$ επιπλέον χώρο (not in-place).



### Quick Sort

_Divide and Conquer_ με βάση **pivot**: αναδιάταξε ώστε τα στοιχεία αριστερά του pivot να είναι μικρότερα και δεξιά μεγαλύτερα, μετά ταξινόμησε αναδρομικά τα δύο μέρη.

```
QuickSort(A, p, r):
    if p >= r: return
    q = Partition(A, p, r)    // επιλέγει pivot, επιστρέφει θέση του
    QuickSort(A, p, q-1)
    QuickSort(A, q+1, r)
```

| Περίπτωση | Recurrence | Λύση |
|-|-|-|
| Best / Average | $T(n) = 2T(n/2) + \Theta(n)$ | $\Theta(n \log n)$ |
| Worst (pivot = min ή max) | $T(n) = T(n-1) + \Theta(n)$ | $\Theta(n^2)$ |

_Παρατήρηση_: in-place, αλλά worst case $\Theta(n^2)$ — γι' αυτό στην πράξη χρησιμοποιείται τυχαίο pivot.



### Heap Sort

Χτίζει **max-heap** από τον πίνακα, μετά επανειλημμένα εξάγει το μέγιστο.

```
HeapSort(A):
    BuildMaxHeap(A)            // Θ(n)
    for i = n downto 2:
        swap(A[1], A[i])       // βάλε το max στο τέλος
        MaxHeapify(A, 1, i-1)  // Θ(log n)
```

$$ \boxed{\Theta(n \log n)} \text{ σε όλες τις περιπτώσεις, in-place} $$



### Quick Select — Εύρεση $i$-οστού Στοιχείου

**Πρόβλημα**: βρες το $i$-οστό μικρότερο στοιχείο χωρίς πλήρη ταξινόμηση.

```
QuickSelect(A, p, r, i):
    if p == r: return A[p]
    q = Partition(A, p, r)
    k = q - p + 1             // τάξη του pivot στο A[p..r]
    if i == k:   return A[q]
    elif i < k:  return QuickSelect(A, p, q-1, i)
    else:        return QuickSelect(A, q+1, r, i-k)
```

| Περίπτωση | Recurrence | Λύση |
|-|-|-|
| Best / Average | $T(n) = T(n/2) + \Theta(n)$ | $\Theta(n)$ |
| Worst | $T(n) = T(n-1) + \Theta(n)$ | $\Theta(n^2)$ |

**Απόδειξη average case $\Theta(n)$**: με τυχαίο pivot, η αναμενόμενη αναδρομή πέφτει σε υποπρόβλημα μεγέθους $\leq \frac{3}{4}n$ με πιθανότητα $\frac{1}{2}$. Με επαγωγή: $\mathbb{E}[T(n)] \leq cn$ για κατάλληλο $c$.



### Max & Min με $\leq \frac{3n}{2}$ Συγκρίσεις

**Πρόβλημα**: βρες ταυτόχρονα το μέγιστο και ελάχιστο από $n$ στοιχεία κάνοντας το λιγότερες συγκρίσεις.

**Αλγόριθμος** (ζευγάρωμα):
1. Χώρισε τα στοιχεία σε $n/2$ ζεύγη — σύγκρινε μέσα σε κάθε ζεύγος ($n/2$ συγκρίσεις).
2. Βρες το min ανάμεσα στους «μικρούς» κάθε ζεύγους ($n/2 - 1$ συγκρίσεις).
3. Βρες το max ανάμεσα στους «μεγάλους» κάθε ζεύγους ($n/2 - 1$ συγκρίσεις).

$$ \text{Σύνολο} = \frac{n}{2} + 2\left(\frac{n}{2} - 1\right) = \frac{3n}{2} - 2 \quad \Rightarrow \quad \boxed{\leq \frac{3n}{2} \text{ συγκρίσεις}} $$



### Non-Comparison Sorting

#### Counting Sort

**Ιδέα**: μέτρα πόσες φορές εμφανίζεται κάθε τιμή, μετά ανακατασκεύασε.

```
CountingSort(A, k):           // στοιχεία στο [0, k]
    C[0..k] = 0
    for i = 1 to n: C[A[i]]++
    for j = 1 to k: C[j] += C[j-1]   // prefix sums
    for i = n downto 1:
        B[C[A[i]]] = A[i]
        C[A[i]]--
    return B
```

$$ \boxed{\Theta(n + k)} $$

Πρακτικό όταν $k = O(n)$, δηλαδή το εύρος τιμών είναι ανάλογο του πλήθους.

#### Radix Sort

**Ιδέα**: ταξινόμησε ψηφίο-ψηφίο από το λιγότερο σημαντικό (LSD) στο πιο σημαντικό (MSD), χρησιμοποιώντας stable sort σε κάθε βήμα.

$$ \boxed{\Theta(d(n + k))} $$

όπου $d$ = πλήθος ψηφίων, $k$ = εύρος τιμών ανά ψηφίο. Για σταθερά $d, k$: $\Theta(n)$.

#### Bucket Sort

**Ιδέα**: μοίρασε τα στοιχεία σε $n$ «κάδους» ομοιόμορφα, ταξινόμησε κάθε κάδο (π.χ. insertion sort), ένωσε.

| Περίπτωση | Πολυπλοκότητα |
|-|-|
| Average (ομοιόμορφη κατανομή) | $\Theta(n)$ |
| Worst (όλα στον ίδιο κάδο) | $\Theta(n^2)$ |



### Κάτω Φράγμα Ταξινόμησης με Συγκρίσεις

Κάθε _comparison-based_ αλγόριθμος ταξινόμησης αντιστοιχεί σε ένα **δέντρο απόφασης**: εσωτερικοί κόμβοι = συγκρίσεις, φύλλα = πιθανές μεταθέσεις εξόδου.

**Απόδειξη**:
- Πρέπει να υπάρχουν $\geq n!$ φύλλα (μία ανά μετάθεση).
- Δυαδικό δέντρο ύψους $h$ έχει $\leq 2^h$ φύλλα, άρα $h \geq \log_2(n!)$.
- Από Stirling: $\log_2(n!) = \Theta(n \log n)$.

$$ \boxed{\text{Κάθε comparison sort κάνει } \Omega(n \log n) \text{ συγκρίσεις στη χειρότερη περίπτωση}} $$

_Συνέπεια_: Merge Sort και Heap Sort είναι **ασυμπτωτικά βέλτιστοι** comparison sorts — επιτυγχάνουν το κάτω φράγμα.


### Συνοπτικός Πίνακας

| Αλγόριθμος | Best | Average | Worst | In-place | Stable |
|-|-|-|-|-|-|
| Merge Sort | $\Theta(n \log n)$ | $\Theta(n \log n)$ | $\Theta(n \log n)$ | ❌ | ✅ |
| Quick Sort | $\Theta(n \log n)$ | $\Theta(n \log n)$ | $\Theta(n^2)$ | ✅ | ❌ |
| Heap Sort | $\Theta(n \log n)$ | $\Theta(n \log n)$ | $\Theta(n \log n)$ | ✅ | ❌ |
| Counting Sort | $\Theta(n+k)$ | $\Theta(n+k)$ | $\Theta(n+k)$ | ❌ | ✅ |
| Radix Sort | $\Theta(dn)$ | $\Theta(dn)$ | $\Theta(dn)$ | ❌ | ✅ |
| Bucket Sort | $\Theta(n)$ | $\Theta(n)$ | $\Theta(n^2)$ | ❌ | ✅ |
| Quick Select | $\Theta(n)$ | $\Theta(n)$ | $\Theta(n^2)$ | ✅ | — |

_Stable_: διατηρεί τη σχετική σειρά ίσων στοιχείων.
