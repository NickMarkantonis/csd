# ΗΥ345 - Λειτουργικά Συστήματα
## Αλγόριθμοι Αντικατάστασης Σελίδας

- **FIFO**
  Αντικαθιστά τη σελίδα που βρίσκεται πιο παλιά στη μνήμη, ανεξάρτητα από χρήση.
- **LRU**
  Αντικαθιστά τη σελίδα που χρησιμοποιήθηκε λιγότερο πρόσφατα, υποθέτοντας ότι οι πρόσφατα χρησιμοποιημένες θα ξαναχρησιμοποιηθούν σύντομα.
- **NRU**
  Χωρίζει τις σελίδες σε κατηγορίες ανάλογα με τα bits αναφοράς και τροποποίησης και επιλέγει τυχαία μια σελίδα από τις λιγότερο πρόσφατα χρησιμοποιημένες.
- **Second-Chance**
  Παρόμοιο με FIFO, αλλά δίνει μια δεύτερη ευκαιρία σε σελίδες που έχουν bit αναφοράς = 1, αναβαθμίζοντας τη θέση τους στην ουρά.
- **NFU (Counter)**
  Κρατά μετρητή για κάθε σελίδα που αυξάνεται κάθε φορά που η σελίδα χρησιμοποιείται. Αντικαθιστά τη σελίδα με τον χαμηλότερο μετρητή.
- **NFU (aging)**
  Βελτίωση του NFU που μετατοπίζει τον μετρητή δεξιά σε κάθε χρονικό διάστημα, δίνοντας μεγαλύτερη βαρύτητα στη πρόσφατη χρήση.
- **Working Set Model**
  Κρατά τη “δουλεύουσα συλλογή” (working set) των σελίδων που χρησιμοποιεί ενεργά μια διεργασία για να αποφευχθεί thrashing.
- **WSCLock**
  Συνδυάζει Working Set με Second-Chance, αντικαθιστώντας σελίδες εκτός του working set με βάση ένα ρολόι.
- **Thrashing**
  Κατάσταση όπου η CPU ξοδεύει περισσότερο χρόνο σε σφάλματα σελίδας παρά στην εκτέλεση διεργασιών, λόγω ανεπαρκούς μνήμης.
- **Page Size**
  Το μέγεθος κάθε σελίδας, που επηρεάζει την εξωτερική κατακερματισμό και την απόδοση αντικατάστασης.
