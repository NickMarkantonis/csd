## HY220 - Εργαστήριο Ψηφιακών Κυκλωμάτων
### Εισαγωγή στην Verilog



**Σημειώσεις για τη Verilog**

### 1. Εξέλιξη Σχεδίασης Ψηφιακών Κυκλωμάτων
- Η σχεδίαση ψηφιακών κυκλωμάτων έχει εξελιχθεί σημαντικά τα τελευταία 50 χρόνια.
- Αρχικά χρησιμοποιήθηκαν λυχνίες (vacuum tubes) και transistors.
- Με την έλευση των ολοκληρωμένων κυκλωμάτων (ICs) εμφανίστηκαν διάφορα επίπεδα ολοκλήρωσης:
  - **SSI (Small Scale Integration)**: Λίγες πύλες.
  - **MSI (Medium Scale Integration)**: Εκατοντάδες πύλες.
  - **LSI (Large Scale Integration)**: Χιλιάδες πύλες.
  - **VLSI (Very Large Scale Integration)**: Εκατομμύρια πύλες.
- Για τη σχεδίαση χρησιμοποιούνται εργαλεία Electronic Design Automation (EDA) και γλώσσες περιγραφής υλικού (HDLs).

### 2. Ροή Σχεδίασης (Design Flow)
- Περιλαμβάνει τα παρακάτω στάδια:
  1. **Ορισμός απαιτήσεων**.
  2. **Προσομοίωση RTL μοντέλου**.
  3. **Σύνθεση (Synthesis)**.
  4. **Τοποθέτηση και Δρομολόγηση (Place & Route)**.
  5. **Χρονική Ανάλυση (Timing Analysis)**.
- Δύο κύριες μεθοδολογίες σχεδίασης:
  - **Top-Down**: Ξεκινά από το γενικό σύστημα και καταλήγει σε επιμέρους υπομονάδες.
  - **Bottom-Up**: Ξεκινά από βασικά στοιχεία και συνθέτει το σύστημα.
  - Συνήθως χρησιμοποιείται συνδυασμός των δύο.

### 3. Verilog: Τι είναι;
- **Verilog HDL (Hardware Description Language)**: Χρησιμοποιείται για την περιγραφή και προσομοίωση ψηφιακών κυκλωμάτων.
- Βασικά χαρακτηριστικά:
  - **Παραλληλισμός (Concurrency)**: Τα σήματα και τα μπλοκ εκτελούνται ταυτόχρονα.
  - **Χρονισμός (Timing Semantics)**: Διαχείριση του χρόνου με ακρίβεια.
  - **Προγραμματιστική λογική**: Δομές όπως if-else, case κτλ.
- Εφαρμογές: Χρησιμοποιείται σε σχεδίαση επεξεργαστών (Intel, AMD, ARM κ.λπ.) και ASICs.
- Άλλες γλώσσες HDL: VHDL, SystemVerilog, SystemC.

### 4. Συντακτικά Στοιχεία της Verilog
#### Βασικοί Κανόνες
- **Case sensitive**: Οι λέξεις-κλειδιά γράφονται με μικρά γράμματα.
- **Σχόλια**:
  - `//` για σχόλια μίας γραμμής.
  - `/* ... */` για πολλαπλές γραμμές.
- **Τιμές bit**:
  - `0`: Λογικό 0.
  - `1`: Λογικό 1.
  - `x`: Άγνωστη τιμή.
  - `z`: Ασύνδετο σήμα (high impedance).

#### Αναπαράσταση Αριθμών
- Μορφή: `<size>'<base_format><number>`.
  - `<size>`: Πλήθος bits.
  - `<base_format>`: d (δεκαδικό), h (δεκαεξαδικό), b (δυαδικό), o (οκταδικό).
  - Παράδειγμα:
    ```verilog
    4'b1111   // 15 σε 4 bits (δυαδικό)
    6'h3A     // 58 σε 6 bits (δεκαεξαδικό)
    ```

#### Τελεστές (Operators)
- **Αριθμητικοί**: `+`, `-`, `*`, `/`, `%`
- **Λογικοί**: `!`, `&&`, `||`
- **Σχέσης**: `<`, `>`, `<=`, `>=`
- **Ισοδυναμίας**: `==`, `!=`
- **Bitwise**: `&`, `|`, `^`
- **Shift**: `<<`, `>>`
- **Συνένωση**: `{}`, π.χ. `{A, B}`
- **Conditional**: `x ? y : z`

### 5. Βασική Δομή - Modules
- Ορισμός ενός **module** στην Verilog:
  ```verilog
  module arith(output out1, output out2, input in1, input in2);
  /* ... */
  endmodule
  ```
    ή
  ```verilog
  module arith(
    output out1, 
    output out2, 
    input in1, 
    input in2);
  /* ... */
  endmodule
  ```

- Τα modules μπορούν να περιέχουν άλλα modules (Instances).

- Όπως βλέπουμε υπάρχουν διάφοροι τύποι παραμέτρων για τα modules, συγκεκριμμένα οι βασικοί είναι:
    - `input` (Είσοδος):
    Οι ακροδέκτες εισόδου παρέχουν δεδομένα στο module.
    Είναι μονόδρομοι (μόνο ανάγνωση μέσα στο module).
    - `output` (Έξοδος)
    Οι ακροδέκτες εξόδου μεταφέρουν δεδομένα από το module προς τα έξω.
    Από προεπιλογή είναι wire (εκτός αν δηλωθούν ως reg μέσα σε always).
    - `inout` (Αμφίδρομο)
    Μπορεί να λειτουργήσει ως είσοδος ή έξοδος ανάλογα με το κύκλωμα.
    Συνήθως χρησιμοποιείται σε διαύλους (buses) και απαιτεί tri-state buffer.

### 6. Τύποι Μεταβλητών
Οι βασικοί τύποι μεταβλητών που έχει η verilog είναι:
- **integer**: Αποθυκέυει έναν 32-μπιτό ακέραιο αριθμό
- **wire**: Χρησιμοποιείται για συνδυαστική λογική (δεν αποθηκεύει τιμή).
- **reg**: Αποθηκεύει τιμές και χρησιμοποιείται μέσα σε `always` blocks.
- **tri**: Τριών καταστάσεων σήμα (0,1,Ζ)
- **logic**: Εναλλακτική της SystemVerilog που μπορεί να χρησιμοποιηθεί αντί για `wire` και `reg`.

### 7. Συνδέσεις και Σήματα
- **wire**: Χρησιμοποιείται για συνδυαστική λογική.
- **assign**: Ανάθεση τιμής σε `wire`.
  ```verilog
  wire sum = a ^ b;
  assign sum = a ^ b;
  ```

### 8. Ακολουθιακή Λογική (Sequential Logic)
- Flip-flops και registers χρησιμοποιούν `always @(posedge clk)`.
  ```verilog
  always @(posedge clk) q <= d;
  ```

### 9. Σύνθεση και Προσομοίωση
#### Blocking vs Non-blocking Assignments
- **Blocking (`=`)**: Εκτελείται σειριακά.
- **Non-blocking (`<=`)**: Χρησιμοποιείται για χρονισμένα κυκλώματα.
- **Παράδειγμα**:
  ```verilog
  always_ff @(posedge clk) begin
    a <= b;
    c <= a; // c παίρνει την παλιά τιμή του a
  end
  ```

### 10. Testbenches και Προσομοίωση
- **Testbenches**: Χρησιμοποιούνται για τον έλεγχο των κυκλωμάτων.
  ```verilog
  initial begin
    a = 0; b = 0;
    #5 $display("a: %x, b: %x, s: %x, c: %x", a, b, s, c);
  end
  ```

### 11. Μετρητές (Counters)
- Παράδειγμα 8-bit counter:
  ```verilog
  always_ff @(posedge clk) begin
    if (reset)
      out <= 0;
    else
      out <= out + 1;
  end
  ```

### 12. Συνθέσιμος και Μη-Συνθέσιμος Κώδικας
- **Synthesizable**: Κώδικας που μπορεί να μετατραπεί σε υλικό (ASIC/FPGA).
- **Non-synthesizable**: Χρησιμοποιείται μόνο για προσομοίωση (π.χ. `initial`).
