# ΗΥ345 - Λειτουργικά Συστήματα
## Βασικά Συγχρονισμού

- **Semaphores**
  Οι σηματοφόροι (semaphores) είναι ένας μηχανισμός συγχρονισμού που χρησιμοποιείται για να ελέγχεται η πρόσβαση σε κοινόχρηστους πόρους κια να αποφέυγονται συνθήκες συναγωνισμού. Έχει δύο βασικές λειτουργίες:
  1. `wait/down`: μειώνει την τιμή του semaphore, αν η τιμή είναι 0 η διεργασία μπλοκάρεται μέχρι να απελευθερωθεί
  2. `signal/up`: αυξάνει την τιμή του semaphore, απελευθερώνει οποιαδήποτε μπλοκαρισμένη διεργασία
- **Mutexes**
  Τα mutexes είναι ένας μηχανισμός συγχρονισμού που χρησιμοποιείται για να εξασφαλήσει ότι μόνο μία διεργασία ή νήμα μπορεί να εκτελεί μία κρίσιμη περιοχή κάθε φορά.
- **Semaphores vs Mutexes**
  Τα mutexes είναι δυαδικά και ανήκουν σε ένα συγκεκριμμένο νήμα ή διεργασία, μόνο αυτό που το κλείδωσε μπορεί και να το ξεκλειδώσει. Το χρησιμοποιούμε για να αποκλείσουμε την κρίσιμη περιοχή από άλλα νήματα ή διεργασίες. Τα semaphores αντίθετα μπορούν να χρησιμοποιηθούν και δυαδικά και αριθμητικά, δεν έχουν ιδιοκτησία που σημαίνει ότι οποιαδήποτε διεργασία μπορεί να κάνει signal, όχι μόνο αυτή που έκανε wait. Τα χρησιμοποιούμε για να αποκλείσουμε την κρίσιμη περιοχή ή και για να συγχρονίσουμε διεργασίες/νήματα. 
- **Busy Waiting vs Blocking**
  Busy Waiting είναι όταν μία διεργασία/νήμα περιμένει συνεχώς ελέγχοντας άν έχει ελευθερωθεί μία κρίσιμη περιοχή που χρειάζεται ενώ blocking είναι όταν μία διεργασία/νήμα χρειάζεται ένα εξωτερικό σήμα για να συνεχίσει την εκτέλεση του.
