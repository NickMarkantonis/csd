### Βασικές Έννοιες

Γράφος $G = (V, E)$ με $|V| = n$ κόμβους και $|E| = m$ ακμές.

- **Κατευθυνόμενος** _(directed)_: οι ακμές έχουν κατεύθυνση $(u \to v)$.
- **Μη κατευθυνόμενος** _(undirected)_: οι ακμές είναι αμφίδρομες $\{u, v\}$.
- **DAG** _(Directed Acyclic Graph)_: κατευθυνόμενος χωρίς κύκλους.
- **Βαθμός κόμβου**: πλήθος ακμών που τον αγγίζουν. Σε κατευθυνόμενο: $\text{indeg}(v)$, $\text{outdeg}(v)$.

Αναπαράσταση:
- **Λίστες γειτνίασης**: $\Theta(V + E)$ χώρος — προτιμάται για αραιούς γράφους.
- **Πίνακας γειτνίασης**: $\Theta(V^2)$ χώρος — προτιμάται για πυκνούς.



### BFS — Breadth First Search

Εξερευνά τον γράφο επίπεδο-επίπεδο. Βρίσκει **συντομότερα μονοπάτια** (σε πλήθος ακμών) από έναν κόμβο $s$.

```
BFS(G, s):
    for each v: color[v] = WHITE, d[v] = +inf, pred[v] = null
    color[s] = GRAY, d[s] = 0
    Q = queue με {s}
    while Q not empty:
        u = dequeue(Q)
        for each neighbor v of u:
            if color[v] == WHITE:
                color[v] = GRAY
                d[v] = d[u] + 1
                pred[v] = u
                enqueue(Q, v)
        color[u] = BLACK
```

$$ \boxed{\Theta(V + E)} $$

_Ιδιότητα_: μετά το BFS, $d[v]$ = συντομότερο μονοπάτι από $s$ στο $v$ **σε πλήθος ακμών** (όχι βάρος).



### DFS — Depth First Search

Εξερευνά τον γράφο σε βάθος. Βασικό εργαλείο για τοπολογική ταξινόμηση, ανίχνευση κύκλων, SCC.

```
DFS(G,s):
    for each v: 
        color[v] = WHITE
        pred[v] = null
    DFS-Visit(G,s)

DFS-Visit(G, u):
    color[u] = GRAY
    for each neighbor v of u:
        if color[v] == WHITE:
            pred[v] = u
            DFS-Visit(G, v)
    color[u] = BLACK
```

$$ \boxed{\Theta(V + E)} $$

**Τύποι ακμών** (σε κατευθυνόμενο):
- _Tree edge_: πηγαίνει σε WHITE κόμβο.
- _Back edge_: πηγαίνει σε GRAY κόμβο → **υπάρχει κύκλος**.
- _Forward/Cross edge_: πηγαίνει σε BLACK κόμβο.

_Ανίχνευση κύκλου_: ο γράφος έχει κύκλο $\iff$ το DFS βρίσκει **back edge**.


### Τοπολογική Ταξινόμηση - *Topological Sort*

**Ορισμός**: γραμμική διάταξη κόμβων DAG ώστε για κάθε ακμή $(u \to v)$, ο $u$ να εμφανίζεται **πριν** τον $v$.

**Γιατί μόνο σε DAG**: αν υπάρχει κύκλος δεν μπορεί να υπάρξει τέτοια διάταξη.

#### Μέθοδος 1 — DFS

```
TopologicalSort-DFS(G):
    τρέξε DFS(G)
    όταν ένας κόμβος u γίνει BLACK, πρόσθεσέ τον στην αρχή μιας λίστας
    return λίστα                      // κόμβοι σε φθίνουσα σειρά f[u]
```

#### Μέθοδος 2 — Kahn (BFS-based)

```
TopologicalSort-Kahn(G):
    υπολόγισε indeg[v] για κάθε v
    Q = queue με όλους τους v που έχουν indeg[v] == 0
    result = []
    while Q not empty:
        u = dequeue(Q)
        result.append(u)
        for each neighbor v of u:
            indeg[v]--
            if indeg[v] == 0: enqueue(Q, v)
    if len(result) != |V|: "ο γράφος έχει κύκλο"
    return result
```

$$ \boxed{\Theta(V + E)} $$

**Bonus — Μη συγκρίσιμα ζεύγη**: δύο κόμβοι $u, v$ είναι _μη συγκρίσιμοι_ αν δεν υπάρχει μονοπάτι $u \to v$ ούτε $v \to u$. Με Kahn: αν σε κάποιο βήμα υπάρχουν $\geq 2$ κόμβοι με indeg $= 0$ ταυτόχρονα, αυτοί είναι μη συγκρίσιμοι. Αλλιώς δεν υπάρχει μη-συγκρίσιμο ζεύγος.



### Dijkstra — Συντομότερα Μονοπάτια (θετικά βάρη)

Βρίσκει συντομότερα μονοπάτια από κόμβο $s$ προς όλους, **μόνο με μη-αρνητικά βάρη**.

```
Dijkstra(G, s):
    d[v] = +inf για κάθε v,  d[s] = 0,  pred[v] = null
    Q = min-heap με όλους τους κόμβους
    while Q not empty:
        u = extractMin(Q)
        for each edge (u, v) with weight w:
            if d[u] + w < d[v]:
                d[v] = d[u] + w        // relax
                pred[v] = u
                decreaseKey(Q, v)
```

| Υλοποίηση Q | Πολυπλοκότητα |
|-|-|
| Binary heap | $\Theta((V + E) \log V)$ |
| Array | $\Theta(V^2)$ |
| Fibonacci heap | $\Theta(E + V \log V)$ |

_Kανόνας επιλογής_: binary heap για αραιούς ($E = O(n \log n)$), array για πυκνούς ($E = \Theta(n^2)$).

**Γιατί ΔΕΝ δουλεύει με αρνητικά βάρη**: ο αλγόριθμος οριστικοποιεί κάθε κόμβο μόλις βγει από την ουρά, υποθέτοντας ότι δεν μπορεί να βρεθεί μικρότερη απόσταση αργότερα. Με αρνητικές ακμές αυτό παραβιάζεται.

_Αντιπαράδειγμα_: $s \to u = 2$, $s \to v = 3$, $v \to u = -2$. Ο Dijkstra δίνει $d[u] = 2$, ενώ το σωστό είναι $3 + (-2) = 1$.

**Δύο κλασικές παγίδες στα θέματα**:
- _Πρόσθεση σταθεράς $C$ για να γίνουν όλα θετικά_: **δεν δουλεύει** — μονοπάτια με διαφορετικό πλήθος ακμών επιβαρύνονται διαφορετικά, άρα αλλάζει ποιο είναι το συντομότερο.
- _Αρνητικές ακμές μόνο από το $s$_: **δουλεύει** — ο $s$ βγαίνει πρώτος και οριστικοποιείται αμέσως, άρα οι αρνητικές ακμές του δεν προκαλούν πρόβλημα.

**Βελτίωση για μικρά ακέραια βάρη** $w \leq W$: αντικατέστησε κάθε ακμή βάρους $w$ με $w$ μοναδιαίες ακμές και τρέξε BFS → $\Theta(V + WE)$, για $W = O(1)$ γίνεται $\Theta(V + E)$.



### Bellman-Ford — Συντομότερα Μονοπάτια (αρνητικά βάρη)

Βρίσκει συντομότερα μονοπάτια από $s$ προς όλους, **ακόμα και με αρνητικά βάρη**. Επίσης ανιχνεύει αρνητικούς κύκλους.

```
BellmanFord(G, s):
    for each v in V:
        d[v] = +inf 
        pred[v] = null 
    d[s] = 0
    for 1 until |V| - 1:
        for each edge (u, v):
            if d[u] + w(u,v) < d[v]:
                d[v] = d[u] + w(u,v)
                pred[v] = u
    for each edge (u, v):
        if d[u] + w < d[v]: return NULL
    return d
```

$$ \boxed{\Theta(VE)} $$

**Γιατί $|V| - 1$ γύρους**: κάθε γύρα εγγυάται ότι τα συντομότερα μονοπάτια με $\leq k$ ακμές έχουν υπολογιστεί. Το μέγιστο απλό μονοπάτι έχει $|V| - 1$ ακμές, άρα αρκούν $|V| - 1$ γύρες.

**Ανίχνευση αρνητικού κύκλου**: αν στην $|V|$-οστή γύρα κάποια απόσταση ξανα-μειωθεί, υπάρχει αρνητικός κύκλος προσβάσιμος από $s$.

**Εύρεση του κύκλου**: όταν βρεθεί κόμβος $v$ που χαλαρώνει, ακολούθησε $\text{pred}$ για $|V|$ βήματα (για να μπεις μέσα στον κύκλο), μετά ακολούθησε ξανά μέχρι να ξαναβρείς τον ίδιο κόμβο.

**Μη κατευθυνόμενοι γράφοι**: οποιαδήποτε αρνητική ακμή $\{u,v\}$ αποτελεί από μόνη της «αρνητικό κύκλο» ($u \to v \to u$) — άρα ο αλγόριθμος δεν εφαρμόζεται ουσιαστικά σε μη κατευθυνόμενους με αρνητικές ακμές.

### Σύγκριση Αλγορίθμων Μονοπατιών

| Αλγόριθμος | Βάρη | Πολυπλοκότητα | Χρήση |
|-|-|-|-|
| BFS | χωρίς (ή $w=1$) | $\Theta(V+E)$ | μοναδιαία βάρη |
| Dijkstra (heap) | $\geq 0$ | $\Theta((V+E)\log V)$ | γενικά θετικά |
| Dijkstra (array) | $\geq 0$ | $\Theta(V^2)$ | πυκνοί γράφοι |
| Bellman-Ford | οποιαδήποτε | $\Theta(VE)$ | αρνητικά / κύκλοι |
| DP σε DAG | οποιαδήποτε | $\Theta(V+E)$ | DAG (shortest ή longest) |
