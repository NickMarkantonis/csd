### Κανόνες Λογαρίθμου

| Κανόνας | Τύπος |
|-|-|
| Γινόμενο | $\log_b(xy) = \log_b x + \log_b y$ |
| Πηλίκο | $\log_b(x/y) = \log_b x - \log_b y$ |
| Δύναμη | $\log_b(x^k) = k \cdot \log_b x$ |
| Βάση | $\log_b 1 = 0 \quad,\quad \log_b b = 1$ |
| Αντίστροφος | $b^{\log_b x} = x$ |
| Αλλαγή βάσης | $\log_b x = \dfrac{\log_c x}{\log_c b}$ |
| Χρήσιμος στο Master | $a^{\log_b n} = n^{\log_b a}$ |

### Ασυμπτωτικές Σημειώσεις

- $f(n) \in O(g(n))$: ο $f$ μεγαλώνει **το πολύ** όσο ο $g$ — _άνω φράγμα_
- $f(n) \in \Omega(g(n))$: ο $f$ μεγαλώνει **τουλάχιστον** όσο ο $g$ — _κάτω φράγμα_
- $f(n) \in \Theta(g(n))$: $O$ **και** $\Omega$ — _ακριβές φράγμα_

Τυπικά:
$$ f(n) \in O(g(n)) \iff \exists c > 0,~ n_0:~ f(n) \leq c \cdot g(n) \quad \forall n \geq n_0 $$

**Ιεραρχία** (από αργό προς γρήγορο):
$$ \Theta(n!) \succ \Theta(2^n) \succ \Theta(n^3) \succ \Theta(n^2) \succ \Theta(n \log n) \succ \Theta(n) \succ \Theta(\log n) \succ \Theta(1) $$

> **Κανόνας:** Σε πολυώνυμο κρατάμε μόνο τον υψηλότερο όρο και πετάμε σταθερές: $5n^2 + 100n + 7 = \Theta(n^2)$.

### Τύποι Αλγορίθμων

- **_Divide and Conquer_**: Σπάσε το πρόβλημα σε μικρότερα, λύσε αναδρομικά, ένωσε τις λύσεις.
  _Παραδείγματα:_ Merge Sort, Quick Sort, binary search.

- **_Greedy_**: Σε κάθε βήμα κάνε την τοπικά βέλτιστη επιλογή χωρίς να κοιτάς πίσω.
  _Παραδείγματα:_ Kruskal, Prim, Huffman, fractional knapsack.

- **_Dynamic Programming_**: Σπάσε σε υποπροβλήματα που **επικαλύπτονται** — αποθήκευσε τις λύσεις τους για να μην τα ξαναλύσεις.
  _Παραδείγματα:_ 0-1 knapsack, matrix chain multiplication, Bellman-Ford.

- **_Graph Traversal_**: Συστηματική εξερεύνηση γράφου.
  _Παραδείγματα:_ BFS (επίπεδα), DFS (βάθος), topological sort.

> Αν ένας greedy **αποτυγχάνει**, συνήθως χρειάζεσαι DP. Αν ο DP είναι πολύ αργός για το πρόβλημα, κοίτα αν είναι NP-hard.

### Βασικές Πολυπλοκότητες Αλγορίθμων

| Αλγόριθμος | Worst Case |
|-|-|
| Binary Search | $\Theta(\log n)$ |
| Merge Sort | $\Theta(n \log n)$ |
| Quick Sort | $\Theta(n^2)$ worst, $\Theta(n \log n)$ avg |
| Heap Sort | $\Theta(n \log n)$ |
| BFS / DFS | $\Theta(V + E)$ |
| Dijkstra (binary heap) | $\Theta((V + E) \log V)$ |
| Dijkstra (array) | $\Theta(V^2)$ |
| Bellman-Ford | $\Theta(VE)$ |
| Prim (binary heap) | $\Theta(E \log V)$ |
| Kruskal | $\Theta(E \log E)$ |
| Topological Sort | $\Theta(V + E)$ |

### Γράφοι — Βασικοί Ορισμοί

- **Συνδετικό Δέντρο** _(Spanning Tree)_: δέντρο που καλύπτει όλους τους κόμβους — $V-1$ ακμές, χωρίς κύκλους.
- **MST** _(Minimum Spanning Tree)_: spanning tree ελάχιστου συνολικού βάρους.
- **DAG** _(Directed Acyclic Graph)_: κατευθυνόμενος γράφος χωρίς κύκλους → επιτρέπει topological sort.
- **Τοπολογική Διάταξη**: γραμμική διάταξη κόμβων DAG ώστε κάθε ακμή να πηγαίνει «αριστερά → δεξιά».

### Κλάσεις Πολυπλοκότητας

- **P**: προβλήματα που _λύνονται_ σε πολυωνυμικό χρόνο.
- **NP**: προβλήματα που _επαληθεύονται_ σε πολυωνυμικό χρόνο.
- **NP-complete**: στο NP **και** το δυσκολότερο — κάθε NP πρόβλημα ανάγεται σε αυτό.
- **NP-hard**: τουλάχιστον τόσο δύσκολο όσο τα NP-complete, αλλά δεν χρειάζεται να είναι στο NP.

$$ P \subseteq NP, \quad \text{αλλά αν } P = NP \text{ δεν ξέρουμε} $$

> Αν αποδείξεις ότι ένα πρόβλημα $X$ είναι NP-complete, αναζήτα **προσεγγιστικό** αλγόριθμο αντί για ακριβή.

### Χρήσιμα Μαθηματικά

**Γεωμετρική σειρά** — εμφανίζεται παντού στα recursion trees:
$$ \sum_{k=0}^{m} r^k = \frac{1 - r^{m+1}}{1 - r} \qquad \xrightarrow{r < 1,~ m \to \infty} \qquad \frac{1}{1-r} $$

**Stirling** — για το κάτω φράγμα ταξινόμησης:
$$ \log(n!) = \Theta(n \log n) $$

**Υψος πλήρους δυαδικού δέντρου** με $n$ φύλλα $= \log_2 n$.

**Τριγωνική σειρά** — εμφανίζεται στα $\Theta(n^2)$ αλγόριθμους:
$$ \sum_{k=1}^{n} k = \frac{n(n+1)}{2} = \Theta(n^2) $$
